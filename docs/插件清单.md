# Wash 插件清单

> 本文档列出 Wash 已实现的插件、待实现的插件，以及各插件的功能状态。
> 插件位于 `wash-modules/` 目录，纯文本 Lua 脚本，即插即用。
> v0.2.2 起默认不受限模式，插件可直接使用 Lua 原生接口（`io.*`、`os.execute` 等），也可使用 `wash.*` 标准化 API。

## 一、已实现插件（18 个）

### 文件操作

| 插件 | 命令 | 功能说明 | 依赖 API |
|------|------|----------|----------|
| `ls.wash` | `ls [path]` | 列出目录内容 | `read_dir`, `get_cwd`, `print` |
| `mkdir.wash` | `mkdir <dirname>` | 创建文件夹 | `make_dir`, `print` |
| `rmdir.wash` | `rmdir [-r] <dirname>` | 删除目录，`-r` 递归 | `remove_dir`, `is_dir`, `print` |
| `rm.wash` | `rm <filename>` | 删除文件 | `remove_file`, `print` |
| `cp.wash` | `cp <src> <dst>` | 复制文件 | `copy_file`, `is_dir`, `print` |
| `mv.wash` | `mv <src> <dst>` | 移动/重命名文件 | `move_file`, `is_dir`, `print` |
| `touch.wash` | `touch <filename...>` | 创建空文件或更新时间戳 | `write_file`, `file_exists`, `print` |
| `cat.wash` | `cat <filename>` | 读取并打印文件内容 | `read_file`, `print` |
| `tree.wash` | `tree [path] [depth]` | 递归显示目录树 | `read_dir`, `is_dir`, `get_cwd`, `print` |

### 暂不考虑（过于复杂或依赖管道）

| 插件 | 原因 |
|------|------|
| `awk` / `sed` | 实现复杂，需要完整的脚本解释器 |
| `less` / `more` | 需要终端交互控制，当前架构不支持 |
| `vim` / `nano` | 完整文本编辑器，超出插件范围 |
| `ssh` / `scp` | 需要网络库，依赖过重 |
| `chmod` / `chown` | Windows 权限模型与 Unix 不同 |
| `xargs` | 依赖管道机制，待管道实现后再做 |
| `diff` | 算法复杂，优先级低 |

## 三、插件开发规范

1. **文件命名**：`<命令名>.wash`，命令名即文件名（不含后缀）
2. **参数获取**：`local args = ...`，`args` 为数组，`args[1]` 是第一个参数
3. **输出**：推荐使用 `wash.print()`，也可使用原生 `print`
4. **文件操作**：推荐使用 `wash.*` API（路径自动补全），也可使用 `io` 库
5. **进程调用**：推荐使用 `wash.spawn_exe()`，也可使用 `os.execute`
6. **错误处理**：输出错误信息，不主动报错终止
7. **路径处理**：`wash.*` API 的相对路径由内核自动拼接当前 cwd；原生 `io`/`os` 需自行处理
